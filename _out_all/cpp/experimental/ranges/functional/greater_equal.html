Function object for performing comparisons. The primary template invokes operator< on const lvalues of type T and negates the result. The specialization greater_equal<void>

All specializations of greater_equal are Semiregular.

1) Compares x and y. Equivalent to return ! ranges::less <> { } (x, y) ;
2) Compares t and u. Equivalent to return ! ranges::less <> { } ( std::forward <T> (t), std::forward <U> (u) ) ;

Notes

Unlike std::greater_equal, ranges::greater_equal requires all six comparison operators <, <=, >, >=, == and != to be valid (via the StrictTotallyOrdered and StrictTotallyOrderedWith constraints) and is entirely defined in terms of ranges::less. However, the implementation is free to use operator>=
